MY DASHBOARD — BRE'S PLANNER UPDATE

GitHub Pages files
1. Open cpriss1979/my_dashboard.io on GitHub and use the branch that
   publishes your dashboard.
2. Choose Add file > Upload files. Select the .html, .js, and .css files
   from this ZIP, keeping them in the repository root. Commit the upload.
   These are complete replacement files. Leave the other repo files in place.
3. When GitHub Pages finishes building, reopen My Dashboard and refresh.

Find the new features
- Tasks has the four-quadrant priority board. Use the dropdown on a task
  to move it. The checkbox completes the task in your existing Tasks list.
- Open Focus timer from the sidebar or More on a phone. Start with 25
  minutes of focus, a 5-minute break, or a 15-minute long break. You can
  change those durations under Timer settings.
- Open Quick links in the sidebar or More. Add a label, website URL, and
  an optional emoji, then choose Pin link.
- Under Finances > Savings, choose Add fund. Funds assign money you
  already have in a savings account. Release returns the assigned amount
  to the account's unassigned total. Older savings goals keep their names
  and targets. Enter an amount to set aside if you want to fund them.
- The Shopping and Wish lists have independent paper colors. Set a list
  emoji by the color picker or an item emoji in its editor. Check a finished
  item to move it to the archive. Open the archive to restore or delete it.
- Add an Emoji sticker in the Journal or Calendar entry editor.

Enable sharing in Firebase
1. Open Firebase Console > Firestore Database > Rules for the
   my-dashboard-95981 project. Keep a copy of the current published rules.
2. If the live rules match the rules from your repository, paste the
   complete included firestore.rules and choose Publish. If your live
   rules contain extra sections you added, retain those sections and add
   the new signedInOwner, verifiedRecipient and shareScope functions and
   the two new sharing match blocks. Keep your existing user and widget
   rules. Sharing needs the published rules in addition to the GitHub files.
3. Sign in, let your dashboard finish syncing, then open Sharing. Enter
   the guest's sign-in email and select Calendar only, Finances + Calendar,
   or Whole dashboard. Save the invitation and send them the copied link.
4. The guest opens the link and signs in with that verified email. They
   get a view-only dashboard. You can change their scope or revoke the
   invitation from Sharing. Whole dashboard access includes journal entries
   and drafts. Calendar-only access cannot read your finance records.

Setup order
You can use the planner features as soon as GitHub Pages publishes the
files. Enable the Firestore rules when you are ready to use invitations.
