GLOWCODE GAMES — BATCH 1

INSTALL
Upload ALL files and the activities/ folder to the root of your existing GitHub Pages repository, replacing matching files. Keep the folder structure. This includes games-extension.js, activities.css, and activities/*.mjs. No npm/build step, new API key, or Firebase rule change is needed. The prior dashboard redesign, account login, sync, icons and sections are retained.

TWO CATEGORIES
Play & Puzzles: Water Sort, Memory Match, and the 13 existing games.
Relax & Unwind: Ripple Pond and Glow Sand.
Only these first four requested additions are included in this batch. There are no placeholder tiles for future games.

WATER SORT
Select a source bottle and a matching or empty destination. Levels are generated by reversible moves from a solved board, giving each level a verified legal solution. Undo, hint solver, pause, restart and next level. Current board/history/level save in your account's existing dashboard state.

MEMORY MATCH
Three difficulty choices (6/8/12 pairs), default Untimed mode, optional elapsed-time mode, moves/pairs, pause and restart. Current deck, matches, open cards, settings and elapsed time save. Tab/Enter operate cards.

RIPPLE POND
Tap/drag for gentle ripples; place floating petals. Arrow keys move the ring; Space/Enter interact. Optional sound (always off when opening), volume, pause, reduced motion and restart. Petals/settings save; water ripples are transient. No countdown, score or failure states.

GLOW SAND
Draw or rake pastel sand, adjust brush/color, undo and restart. Pointer/touch drawing; arrows move, Shift+arrows draw, Space/Enter stamp. Artwork/settings save. Optional sound begins off; reduced-motion setting available. Art is bounded to 80 strokes/4,000 points so it stays practical for existing sync; a full-canvas message asks you to Undo/Restart instead of silently deleting artwork.

STORAGE / LIFECYCLE
Progress is under state.glowActivities in the existing myday-v1 data, included in the existing backup and account sync. No new storage namespace or cloud permissions. Leaving or changing accounts disposes listeners/loops/audio and prevents late async imports or departing activities from writing to another account. Modules load only when selected. Normal page scrolling remains available outside the canvas/play controls.

PRESERVATION
Original inline scripts/styles (including Journal sparkle implementation) and all original finance, games, auth/sync and redesign source files were compared byte-for-byte and are unchanged. The new additions are separate files.

CHECKS
Each activity was implemented and tested before the next. Water Sort: 40 generated levels checked with a legal solution certificate and solver. Memory: deck/pair rules, mismatch, difficulty/mode, pause and cleanup. Pond/Sand: interaction, restore/settings, silent default, restart and cleanup. DOM integration at 320/375/390/430/900/1440; lazy imports, saved progress, category navigation, audio opt-in/cleanup, account isolation and late-import cancellation. Mocked account sync transfers artwork/progress via the original driver. Existing dashboard regression checks retained.

LIMITS
DOM/CSS and algorithm tests are not actual browser/phone rendering or real audio-device tests. Live login, real-device sync, on-screen keyboard and visual/touch behavior still need checking after upload. No real account data was accessed during tests.
