GLOWCODE — GAME LIBRARY & PLACE PHOTOS

INSTALL
Upload ALL files and folders in this package into your existing GitHub repository root, replacing matching files. Keep activities/ and assets/memory-places/ in their exact relative locations. No npm/build step or Firebase setup/rule change is required.

MEMORY MATCH
12 distinct local place photographs (beaches, mountains, waterfalls, gardens, cities and landmarks), square-cropped to 512×512. The same local image and crop are used for each pair. All selected round photos must preload/decode successfully before cards or elapsed play begin. Missing photos show Retry photos rather than a broken round. Card backs are identical and do not contain face images. Matched cards show the place name; a full matched-place list and Photo credits are available. Difficulty 6/8/12 pairs and Untimed/Elapsed-time modes remain. Existing saved decks, matching progress and settings are retained.

PHOTO RIGHTS
11 photographs carry CC0; the Yosemite photograph by Carol M. Highsmith is public domain. Rights/author/source metadata were checked from Wikimedia Commons and stored with the package. Credits and local image hashes:
assets/memory-places/CREDITS.txt
assets/memory-places/credits.json
No random/hotlinked image service is used during play. Credits link to original source pages for reference only.

LIBRARY
Game Library contains 16 remaining games in two alphabetized category grids. Play & Puzzles has 13 games. Relax & Unwind includes Glow Sand, Kaleidoscope and Ripple Pond. Old/new tiles use the same sizing and typography. Grids adapt from 4–5 columns on wide screens to 3 on tablets and 2 on phones. Active category is highlighted.

NAVIGATION
No Choose a game dropdown exists, including in older games. Every game has a consistent ← Game Library button. Category and previous library scroll position return when leaving a game. Useful game controls (difficulty, color choices, pause, sound, restart/New game) remain. Legacy Bowling's header lookup was updated so its difficulty/New game controls still work without the removed dropdown.

BALLOON POP
Removed from the game catalog, library, dedicated functions, styles and embedded zoo asset. Shared city/fireworks and other game code/assets remain. Any old Balloon Pop/invalid selection falls back safely to the library. Historical saved score records were left untouched; no app data was deleted.

PRESERVED
Journal sparkle function, selectors/keyframes and layering CSS are unchanged. Finance functions, auth/sync/storage files and all other activity modules are unchanged. Existing app data and account behavior remain.

CHECKS
All 16 games opened and returned in DOM tests at 320/375/390/430/900/1440/1600 widths. Alphabetical categories, no selector dropdowns, category/scroll restoration, old removed-selection fallback and preserved scores checked. Memory photo preload gate, identical backs, pair image/crop attributes, matched names, difficulty/mode and missing-image retry checked. All 12 JPEGs decoded and their dimensions/hashes/licenses verified. Dashboard editing/saving/finance and mocked account sync regression suites passed.

LIMITS
DOM and CSS checks do not measure actual browser geometry or replace a real-phone test. The local photos were visually inspected; the full dashboard was not rendered in a browser during this session. Real keyboard/touch/safe-area rendering and live account sync remain to be checked after upload. No real user account data was accessed during testing.
