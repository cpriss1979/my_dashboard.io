GLOWCODE — ORIGINAL GAMES & ACTIVITIES

INSTALL
Upload ALL files and folders from this package into your existing GitHub repository root, replacing matching files. Keep activities/ and assets/memory-places/ in their relative locations. This is the complete dashboard, not a patch. No build, npm install, or Firebase/rules changes are needed. This package has not been uploaded to GitHub for you.

WHAT CHANGED
22 working games/activities in one alphabetical Game Library. The six additions are Quiet Clean (original pressure-washing activity), Little Wins, Glow Maze, Fidget Spinner, Milk Jug Toss, and Bubble Wrap. Existing games remain, including Memory Match's local place photographs. Balloon Pop remains removed.

Category tabs now use a purple/blue gradient, white text, bright border and subtle glow for the active category, with a separate underline marker. Inactive tabs are navy/lavender. Keyboard focus, hover and pressed states are distinct. Categories, previous library position and return controls are retained.

Quiet Clean: four original canvas surfaces, saved localized dirt masks, nozzle widths, optional progress, reset/new surface. Hold/drag, Space, or Shift + arrows.
Little Wins: choose, skip, edit or create optional quests; decorative stars and history save without streaks or penalties.
Glow Maze: three generated connected mazes, original diamond/orbiter characters, power-ups, score, lives, difficulty, pause/restart; arrows/WASD, swipe and direction buttons.
Fidget Spinner: original metallic shapes/colors, gesture-driven rotation, adjustable friction, keyboard controls and reduced motion.
Milk Jug Toss: drag-back projectile aim, jug/ball collisions, gravity, platform-only scoring, returning ball, unlimited practice and three-ball challenge.
Bubble Wrap: translucent raised bubbles stay depressed, drag multi-pop, keyboard access, fresh sheet and optional endless sheets.
Ripple Pond: existing saved petal positions become varied original lily pads with V notches, veins, highlights, contact shadows and gentle bobbing. Interactive ripples are retained.

SAVING / SOUND
Progress/settings use state.glowActivities in the existing storage, backup and account-sync system. No real user data is embedded. Sound starts off on every mount and is optional. Reduced-motion controls are available. Activity loops/listeners/audio are cleaned up on exit. The Journal sparkle implementation is unchanged.

LIMITS
DOM tests do not measure actual browser geometry or verify physical touch, real audio, or live Firebase. Full browser rendering and real-phone checks remain to be performed after upload. Original visuals are canvas/CSS artwork, not photographs or third-party game assets. This package preserves the existing authentication/sync implementation and does not change its setup.
